# UX design block 0.1.0

This block turns external examples into traceable product decisions. It never treats a screenshot as a specification and never copies another product's branding.

Each decision must name a user journey, one or more known references, the product-specific adaptation, all critical interaction states and rendered proof. Verbindo is the first implementation: Mobbin search/filter flows inform task starters, inline history and result refinement; Atlassian's empty-state guidance informs recovery actions.
