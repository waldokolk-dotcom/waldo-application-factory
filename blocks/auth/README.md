# Auth adapter 0.1.0 (candidate)
Server-only adapter for official Supabase JS auth.getUser(token). Supply a request-scoped public-key client with session persistence and auto-refresh disabled. Never pass a service-role client. No secrets or tokens logged. Return null on malformed or rejected credentials or upstream errors; callers must deny protected routes on null. Ownership helper accepts only server-verified identity and database-derived owner ID. Database RLS remains mandatory; this is not a role-management system. Do not infer privileges from user_metadata. No registration, SMTP, session or production integration claimed. Unit tests use a mock client; integration requires pinned SDK and real positive/negative tests in Verbindo. Rollback: do not adopt until validated; revert adapter import if integration fails.
