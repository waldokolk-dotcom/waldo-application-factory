# Auth adapter 0.1.0 (approved)
Server-only adapter for official Supabase JS auth.getUser(token). Supply a request-scoped public-key client with session persistence and auto-refresh disabled. Never pass a service-role client. No secrets or tokens logged. Return null on malformed or rejected credentials or upstream errors; callers must deny protected routes on null. Ownership helper accepts only server-verified identity and database-derived owner ID. Database RLS remains mandatory; this is not a role-management system. Do not infer privileges from user_metadata. Unit tests isolate the adapter; disposable local and live acceptance validate the integrated contract. Rollback: revert the consumer integration and restore the registry block to `testing` if a production regression is observed.

Production acceptance combines the adapter with Verbindo's confirmed-email registration, password login, recovery, refresh and logout flows, owner-scoped profile RLS, route-level owner authorization and server-only user administration. Local CI uses disposable GoTrue, Mailpit and PostgREST containers; live acceptance uses an isolated auto-confirmed Verbindo test identity and verifies login plus automatic owner-profile creation. The minimum password length is 12. Supabase leaked-password protection remains unavailable without a Pro subscription and is therefore recorded as a platform-plan limitation under the mandatory zero-new-cost policy; it is not represented as enabled.
