# Operations Center
Independent WAF control plane; consumers remain independent. P0 monitoring, incident, recovery, security-ops, backup, cost-control; P1 support, feedback, notifications, ops-reporting; P2 improvement, knowledge. Preserve six core production gates first; do not activate unverified blocks in consumers. Monitoring must use administrator-configured targets only, bounded checks, no secrets in logs. Recovery requires allowlisted reversible actions, incident evidence, concurrency lock, tests and rollback. Support must isolate tenants, redact personal data and escalate sensitive cases; never invent answers. Backup requires restore drills; cost guard fails closed on unknown paid commitments. Operational dashboard must show measured data and freshness, never fictional status. Initial monitoring adapter is not a scheduler or live monitor. All other operations blocks are planned.
