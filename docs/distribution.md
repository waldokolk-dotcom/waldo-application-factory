# Independent factory distribution
WAF is the upstream source; Verbindo is a consumer, never a runtime dependency. Each consumer owns its runtime, database, identity, secrets and deployment. Export selected registered blocks into a new directory with immutable source commit, version and SHA-256 lock manifest. Preview exports are explicitly non-production. Production exports fail closed until every selected block is production verified. Run from a clean checkout: node distribution/export.mjs verbindo /tmp/waf-preview "$(git rev-parse HEAD)" preview. Never overwrite an existing destination. Consumer integration must occur in a separate branch, verify hashes and dependencies, run consumer tests, then merge and deploy only after approval gates. Rollback uses the previous consumer commit. This initial exporter copies registered entry files only; transitive dependencies, consumer update PR automation and live deployment remain unimplemented. No consumer secrets or data are transferred.
